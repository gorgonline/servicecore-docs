03 · Kurulum · Adım 3

AI asistanınıza bağlayın

claude mcp add --transport http github \ https://api.githubcopilot.com/mcp/ \ --header "Authorization: Bearer TOKENINIZ"
Köşeli parantez KOYMAYIN. Bearer <github_pat_…> yazarsanız bağlantı HTTP 400 ile düşer. Sadece token'ın kendisi.
Token'ı kimseyle paylaşmayın. Herkes kendi token'ını üretir.

04 · Onay

Onaylayan kişi ne yapar

  • 01Öneri linkini açar
  • 02Üstteki Files changed sekmesine tıklar
  • 03Sağ üstteki yeşil Submit review düğmesine basar
  • 04Açılan panelde Approve seçer
  • 05Panelin altındaki Submit review düğmesine basar
İki tane "Submit review" var: biri paneli açar, diğeri onaylar. Approve seçilmezse sadece yorum olur — kilit açılmaz.
04 · Onay

Sonra kilit açılır

Kırmızı yazı kaybolur, yeşil Merge pull request düğmesi çıkar.

"Bypass rules" kutusuna dokunmayın. O acil durum kapısı. Her seferinde kullanılırsa kimse kimsenin yazdığını okumamış olur.
04 · Onay

Kendi önerinizi kendiniz onaylayamazsınız

Denerseniz Approve seçeneği soluk çıkar. Tıklanmaz.

Comment
Yorum bırakır, onay değil
Approve
Kapalı — öneriyi siz açtınız
Request changes
Düzeltme ister
Hata değil — dört göz kuralının kendisi. Yazan ile onaylayan farklı kişi olmalı.
04 · Onay

Kim onaylar

Onaylamak "gördüm" değil, "bu bilgi doğru" demektir.

Olay modülünü bilmeyen biri, olay sayfasının doğru olup olmadığını anlayamaz. O yüzden bölümü bilen kişi onaylar.

Şimdilik varsayılan: Levent ve İbrahim. Biri onaylarsa yeterli.
